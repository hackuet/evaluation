#### Reference Solution: Non-Blocking Concurrency via `millis()`
To achieve true concurrency without blocking the CPU, time-slicing with `millis()` should be used:

```cpp
const uint8_t LED1_PIN = 13;
const uint8_t LED2_PIN = 12;

const unsigned long INTERVAL_LED1 = 1000; // Xs
const unsigned long INTERVAL_LED2 = 3000; // Ys

unsigned long prevMillisLED1 = 0;
unsigned long prevMillisLED2 = 0;

uint8_t stateLED1 = LOW;
uint8_t stateLED2 = LOW;

void setup() {
  pinMode(LED1_PIN, OUTPUT);
  pinMode(LED2_PIN, OUTPUT);
}

void loop() {
  unsigned long currentMillis = millis();

  // Concurrently handle LED1
  if (currentMillis - prevMillisLED1 >= INTERVAL_LED1) {
    prevMillisLED1 = currentMillis;
    stateLED1 = !stateLED1;
    digitalWrite(LED1_PIN, stateLED1);
  }

  // Concurrently handle LED2
  if (currentMillis - prevMillisLED2 >= INTERVAL_LED2) {
    prevMillisLED2 = currentMillis;
    stateLED2 = !stateLED2;
    digitalWrite(LED2_PIN, stateLED2);
  }
}
```

#### Technical Concept & Implementation Guide
Software Pulse Width Modulation (PWM) synthesizes analog-like output on a standard digital pin by switching the pin between `HIGH` and `LOW` at a high frequency (e.g., 100 Hz to 1 kHz):

$$\text{Duty Cycle} = \frac{\text{value}}{255}$$
$$T_{\text{on}} = T_{\text{total}} \times \left(\frac{\text{value}}{255}\right), \quad T_{\text{off}} = T_{\text{total}} - T_{\text{on}}$$

A clean reference implementation of `pwm(pin, value)` without `analogWrite()`:

```cpp
void pwm(uint8_t pin, uint8_t value) {
  // Edge cases
  if (value == 0) {
    digitalWrite(pin, LOW);
    return;
  }
  if (value == 255) {
    digitalWrite(pin, HIGH);
    return;
  }

  // 1 kHz carrier frequency -> total period = 1000 microseconds
  const unsigned long TOTAL_PERIOD_US = 1000;
  
  // Note: Cast to unsigned long prevents 16-bit signed integer overflow on AVR
  unsigned long onTime = (TOTAL_PERIOD_US * (unsigned long)value) / 255;
  unsigned long offTime = TOTAL_PERIOD_US - onTime;

  digitalWrite(pin, HIGH);
  delayMicroseconds(onTime);
  digitalWrite(pin, LOW);
  delayMicroseconds(offTime);
}
```

#### Technical Concept & Implementation Guide
The HC-SR04 ultrasonic distance sensor relies on acoustic time-of-flight:
1. The microcontroller asserts a $10\,\mu\text{s}$ HIGH pulse on the `TRIG` pin.
2. The transducer transmits an 8-cycle ultrasonic burst at 40 kHz.
3. The sensor pulls `ECHO` HIGH for the duration of the sound wave's round trip.
4. Using the speed of sound in dry air ($343\text{ m/s} \approx 0.0343\text{ cm}/\mu\text{s}$):
   $$\text{Distance (cm)} = \frac{\Delta t\,(\mu\text{s}) \times 0.0343\,\text{cm}/\mu\text{s}}{2}$$

While beginner tutorials use the blocking `pulseIn()` function, true embedded implementations avoid `pulseIn()`:

- **Intermediate Solution (Non-blocking edge polling with timeout guard)**:
  ```cpp
  float readSonarCM(uint8_t trigPin, uint8_t echoPin) {
    digitalWrite(trigPin, LOW);
    delayMicroseconds(2);
    digitalWrite(trigPin, HIGH);
    delayMicroseconds(10);
    digitalWrite(trigPin, LOW);

    unsigned long startWait = micros();
    while (digitalRead(echoPin) == LOW) {
      if (micros() - startWait > 30000) return -1.0; // Timeout guard
    }

    unsigned long pulseStart = micros();
    while (digitalRead(echoPin) == HIGH) {
      if (micros() - pulseStart > 30000) return -1.0; // Out of range timeout
    }
    unsigned long duration = micros() - pulseStart;

    return (duration * 0.0343) / 2.0;
  }
  ```

- **Advanced Hardware Acceleration (Timer1 Input Capture / PCINT Interrupt)**:
  Connecting `ECHO` to Pin 8 (`ICP1` on ATmega328P) enables the 16-bit Timer1 Input Capture Unit to automatically latch timer ticks on rising and falling edges with zero CPU polling overhead.
