- **Simulation**: [Wokwi Project 477156139802492929](https://wokwi.com/projects/477156139802492929)
- **Implementation**:
  ```cpp
  const int LED1=8;
  const int LED2=9;
  unsigned long previousled1=0;
  unsigned long previousled2=0;
  const unsigned long intervalled1=100, intervalled2=500;
  bool ledstate1=0, ledstate2=0;

  void setup() {
    pinMode(LED1,OUTPUT);
    pinMode(LED2,OUTPUT);
  }

  void loop() {
    unsigned long currentTime=millis();
    if(currentTime-previousled1 >= intervalled1){
      previousled1 = currentTime;
      ledstate1=!ledstate1;
      digitalWrite(LED1,ledstate1);
    }
    if(currentTime-previousled2 >=intervalled2){
      previousled2=currentTime;
      ledstate2=!ledstate2;
      digitalWrite(LED2,ledstate2);
    }
  }
  ```
- **Merits**:
  - Independent non-blocking timing using `millis()`.
  - Correct use of `unsigned long` for timer arithmetic avoiding rollover bugs.
  - Distinct intervals ($100\text{ ms}$ and $500\text{ ms}$) executing concurrently.

### Task 2: Software PWM ([`task2_software_pwm.ino`](file:///home/user/Projects/HACK%20Evaluation/batches/2k25/assignment-1/submissions/52507068/task2_software_pwm.ino))
- **Simulation**: [Wokwi Project 477406191426135041](https://wokwi.com/projects/477406191426135041)
- **Implementation**:
  ```cpp
  const int led = 9;
  const unsigned long pwm_period = 200000; //micro seconds
  int brightness = 200;

  void setup() {
    pinMode(led,OUTPUT);
  }

  void loop() {
    unsigned long elapsed = micros() % pwm_period;
    unsigned long ontime = (pwm_period * (unsigned long) brightness)/255;
    if(elapsed < ontime){
      digitalWrite(led, HIGH);
    } else {
      digitalWrite(led, LOW);
    }
  }
  ```
- **Merits**:
  - Completely avoids `analogWrite()`.
  - Calculates on-time dynamically using modular microsecond elapsed phase: `elapsed = micros() % pwm_period`.
  - Explicit cast `(unsigned long) brightness` prevents 16-bit integer multiplication overflow on AVR architecture.
- **Observations & Deductions**:
  - The period is set to $200,000\,\mu\text{s}$ ($5\text{ Hz}$). While the student explains this was chosen to observe the modulation visually in the simulator, standard software PWM operates above $100\text{ Hz}$ to create continuous perceived dimming without flashing.

### Task 3: Sonar Reader ([`task3_sonar_reader.ino`](file:///home/user/Projects/HACK%20Evaluation/batches/2k25/assignment-1/submissions/52507068/task3_sonar_reader.ino))
- **Simulation**: [Wokwi Project 477588106370448385](https://wokwi.com/projects/477588106370448385)
- **Implementation**:
  ```cpp
  const byte trig_pin = 7;
  const byte echo_pin = 2;

  volatile unsigned long echostart = 0;
  volatile unsigned long echoDuration = 0;
  volatile bool measurementReady = false;

  void echo_changed(){
    if(digitalRead(echo_pin)==HIGH){
      echostart = micros();
    } else {
      echoDuration = micros() - echostart;
      measurementReady = true;
    }
  }

  void setup() {
    Serial.begin(9600);
    pinMode(trig_pin, OUTPUT);
    pinMode(echo_pin, INPUT);
    digitalWrite(trig_pin,LOW);

    attachInterrupt(
      digitalPinToInterrupt(echo_pin),
      echo_changed,
      CHANGE
    );
  }
  ```
- **Merits**:
  - True hardware acceleration: utilizes hardware external interrupt INT0 (pin 2) configured for `CHANGE` triggers.
  - Zero blocking: eliminates `pulseIn()`, freeing CPU cycles for other tasks.
  - Concurrency safety: variables accessed in the ISR are properly declared `volatile`.
  - Atomic access: safely copies `echoDuration` inside a `noInterrupts()` / `interrupts()` critical section in `loop()`.
- **Score**: **25.00 / 25**
